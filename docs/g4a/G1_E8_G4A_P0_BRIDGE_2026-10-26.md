## 3. Required convergence contract before implementation

**GATE A — G1 OS ownership and exclusive API**

- Deploy the storage engine under a dedicated UID with protected DB, WAL,
  SHM, source JSON, quarantine marker/sentinel/release-pending, G3 owner
  marker/sentinel, lock files and **all parent directories**.
- Worker UID has no writable mount or direct SQLite access. SO_PEERCRED
  and signed, scoped grants authorize an allowlisted G1 IPC operation.
- Same-UID/root threat is not prevented by file permissions; bound the
  threat explicitly and use an independently operated witness for detection.
- The production/normal G4-A code must not retain an alternate local
  `admit_created` or `settle` mutation entry point reachable by workers.

**GATE B — one E8 wire protocol and independent trust**

- Publish one canonical head schema, signature context, expected-head CAS
  semantics, scope, epoch, trust generation, quarantine digest, local
  business-state digest, request/operation/transaction/payload/grant IDs,
  expiry, one-time token and signed response-binding.
- Select and review the authorization model (e.g. PREPARE/reserve →
  local durable settlement → FINALIZE/reconcile). A witness CAS is not
  atomically committed with local SQLite; never claim cross-store ACID.
- Witness signing and freshness roots are provisioned out of band on a
  separate host/administration domain. A same-run generated public key
  mounted read-only is not independent pinning.
- Every activation/release of authoritative quarantine, including
  *previously valid inactive mark restoration*, must be checked against
  the independently retained **latest** head before new admission.
  An unanchored local active mark must never be treated as a valid release.
- Crash/ACK loss and concurrent CAS require `OUTCOME_UNKNOWN`,
  `LOCAL_COMMITTED_WITNESS_PENDING`, or equivalent durable states and
  explicit STATUS/reconciliation. Neither uncertainty nor an E8 CMT
  alone grants provider execution.

**GATE C — G4-A transaction integration**

- Add an **opt-in experimental** G1-mediated G4-A adapter, preserving
  existing production HOLD and avoiding mutation of PR #73/#79.
- Under a coherent G1 lock/transaction, reconstruct a strict digest of
  **actual** G4-A tables, schema, authority epoch and quarantine artifacts.
  Reject unknown/unattested rows or source/trust changes.
- Bind grant, witness CAS, current head and proposed G4-A transition to
  the **same** operation before `admit_created` or `settle`; enforce
  idempotence before replay, and recheck revocation/quarantine at the
  final linearization point.
- Explicitly separate a **simulated** local G4-A receipt from a verified
  real-world provider effect. This tranche does **not** authorize a
  provider adapter or live dispatch.
